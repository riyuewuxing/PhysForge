# PhysForge 教学法与教室大屏 UX 规范（Pedagogy & Classroom UX Guide）

## 1. 四维同步表征设计原则（Multiple Representations）
每个旗舰仿真应尽可能协同呈现以下四个维度，降低认知负荷并建立直观物理图景与数学抽象之间的桥梁：
1. **动态实体视窗**：Canvas 2D 高帧率真实空间运动 + **Strobe 频闪打点**（模拟打点计时器/频闪照片）。
2. **微观与抽象图层**：独立可开关图层（速度/加速度/受力矢量、场线/等势面、临界包络圆/圆心连线、辅助角度）。
3. **高频同步示波器（`uPlot`）**：实时绘制 $x-t$、$v-t$、$a-t$、$E-t$、$I-t$ 等曲线，支持时间轴游标与实体状态**双向回放联动**。
4. **实时公式与能量仪表盘（`KaTeX`）**：动态展示参数代入公式的实时计算结果及分项能量转化堆叠图。

## 2. POE 探究循环（Predict → Observe → Explain）
- **Predict（预测）**：开启课堂“POE 预测遮罩”后，自动遮蔽预测轨迹线、临界点标记与示波器曲线，引导学生在黑板或口头作出物理预测。
- **Observe（观察）**：解除遮罩运行仿真，借助慢动作（$0.1\times$–$0.5\times$）、频闪打点与临界自动停驻观察真实演化。
- **Explain（解释）**：暂停在临界状态并开启 Excalidraw 透明批注层直接作图推导，结合能量柱状图完成定量归因。

## 3. 教室触控大屏（希沃 / 鸿合一体机）硬性 UX 约束
- **字号与对比度**：大屏模式下全局正文与读数不低于 `18px`，提供“黑板护眼深蓝（Navy Chalkboard）”与“投影仪高对比白底（Projector High-Contrast）”双主题。
- **触控热区**：所有按钮、预设切换键、图层开关及滑块手柄最小交互热区不低于 `44px × 44px`。
- **绝对离线与单文件切片**：课堂环境默认断网，严禁任何外网字体/CDN 请求；`apps/singlefile-exporter` 仅打包单个目标模型 + 壳层 + `uPlot` + `KaTeX`，确保双击即开。

## 4. 教研防幻觉标准（Learning Design Guardrails）
- **POE 任务单**：必须绑定有效 `modelId` 与 `presetId`。
- **变式题组**：母题 + 基础/进阶/压轴三层变式，每道题均须附带对应可运行 Preset 绑定与 `verification` 数值验算元数据。
- **前概念诊断卡**：针对典型迷思概念（如“洛伦兹力做功”“波形图当振动图”）必须绑定可直观证伪的“反例仿真预设”。
