# 高中物理课标与人教版教材映射表（Curriculum Map）

> 对齐标准：《普通高中物理课程标准（2017年版2025年修订）》与人教版（2019）普通高中教科书《物理》全 6 册。

## 1. 四大核心素养标签（枚举基准）
所有仿真模型与教研资产在 `meta.curriculumTags` 中必须使用以下标准枚举：
1. `物理观念`（物质观、运动与相互作用观、能量观）
2. `科学思维`（模型建构、科学推理、科学论证、质疑创新）
3. `科学探究`（问题、证据、解释、交流）
4. `科学态度与责任`（科学本质、科学态度、社会责任）

## 3. 难度分级规范
- `基础新授`：面向高一/高二新课导入，侧重直观现象与核心规律建立（POE 冲突导入）。
- `高三一轮`：面向规律综合、动态分析与典型模型拆解（多表征图像联动）。
- `压轴专题`：面向多过程临界状态、极值包络与高考压轴定量建模。
