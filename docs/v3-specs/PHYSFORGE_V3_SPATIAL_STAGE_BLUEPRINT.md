## 四、五大核心演说引擎施工规格（含工程避坑红线）

### 1. 程序化 3D PBR 物理舞台引擎（`packages/stage-3d`）

#### (1) 工作室光照与高对比双主题（快捷键 `T`）
* 使用 `PMREMGenerator` + `RoomEnvironment` 生成无外网贴图的柔和金属/玻璃反射环境，叠加 1 盏主软阴影方向光（`PCFSoftShadowMap`）+ 1 盏轮廓补光 + 接地刻度圆形微光平面（Contact Grid Floor）。
* **双主题严格遵循教室投影防泛白标准（正文与公式对比度 $\ge 7:1$）**：
  * **暗夜天文台（Dark Obsidian，教室大屏默认）**：深蓝黑径向渐变背景 `#090E1A` $\to$ `#131C31`，荧光粒子、激光束与矢量箭头对比度极高且不刺眼。
  * **白昼物理馆（Daylight Studio，Ciechanowski 风格）**：温润浅灰白 `#F3F6FA`，拉丝铝、陶土、红铜、钴蓝实体材质配柔和落地阴影，适合强采光教室与科普录屏。

#### (2) 程序化物理道具工厂（`ProceduralPropKit`）
以纯数学几何封装高频物理实体，确保 22 个 3D 单元共享统一顶级美术水准且零 `.glb` 体积开销：
* **力学道具**：倒角拉丝金属物块、带刻度与支架的立体透明/实心斜面、动态实时变形的 3D 螺旋金属弹簧（随弹性势能微发光）、带纹理滚动与真实相对划痕层的 3D 传送带、带凹槽金属定/动滑轮与张紧细绳、透明光滑圆弧轨道与天体自转球体（程序化 Canvas 贴图生成轨道环与光晕）。
* **电磁道具**：半透明体积感磁场盒/圆柱（内含 `InstancedMesh` 3D 磁感线与 $\otimes/\odot$ 空间锚点）、红铜光泽绕线线圈/螺线管/平行导轨、发光带电粒子核心与 screen-space 恒宽 `Line2` 渐变光带轨迹、**3D 电势能地形网格**（将静电场直观渲染成“电荷山峰与低谷”）。
* **光波道具**：物理质感玻璃棱镜/凸凹透镜、发光激光柱与虚线法线、3D 实时动态高度场水波/电磁波曲面网格（波峰波谷着色映射）。
* **3D 物理矢量与标牌**：`Vector3DArrow`（柱体 + 锥头 + 透明虚线正交分量投影，悬停高亮）+ `CSS2DRenderer` 渲染锐利 KaTeX 浮动标签。
  * **`CSS2DRenderer` 防遮挡硬规**：其 DOM 容器必须强制设置 `pointer-events: none`、`position: absolute; inset: 0` 并包裹在独立 CSS 层叠上下文 `isolation: isolate; z-index: 10` 内，仅对需点击的互动标签单独开 `pointer-events: auto`，绝不阻断 3D 旋转与 HUD 点击。

#### (3) 希区柯克无缝 $3\text{D} \leftrightarrow 2\text{D}$ 变形切镜（`SeamlessOrthoCamera`，快捷键 `D`）
解决“学生看懂 3D 动画却画不出试卷 2D 受力图”的最大教学痛点，同时严格避开 `camera-controls` 混用相机陷阱：
1. **双相机统一封装**：维护共享目标点与视锥基准高度 $H$ 的 `PerspectiveCamera` 与 `OrthographicCamera`；仅在交互稳态时由 `camera-controls` 接管当前激活相机。
2. **切往 2D 正交态（`toOrtho2D`）**：
   * 先通过 `camera-controls` 在 $300\text{ ms}$ 内将视角对齐至模型指定的标准剖面法向（如正面 $+Z$ 或俯视 $+Y$）；
   * 在随后的 $550\text{ ms}$ 内执行 Dolly Zoom：将透视相机 `fov` 从 $45^\circ$ 按缓动曲线平滑压至 $3.5^\circ$，同步按公式
     $$d(t) = \frac{H}{2\tan\left(\frac{\text{fov}(t)}{2}\right)}$$
     拉远相机距离，保持目标物体在屏幕中的像素尺寸恒定不变，透视纵深平滑归零；
   * 在 $\text{fov} \le 3.6^\circ$ 的零跳变瞬间无缝切换为 `OrthographicCamera`，同步将 `camera-controls` 的滚轮行为切换为 `ZOOM`（规避正交相机不支持 `DOLLY` 的库限制），并淡入 2D 试卷辅助圆、角度弧线与虚线标尺！
3. **切回 3D 透视态（`toPerspective3D`）**：按逆流程瞬间切回 `PerspectiveCamera`（初始化 $\text{fov} = 3.6^\circ$ 等价距离）再平滑展开至 $45^\circ$ 并优雅环绕至预设 3D 景别。

#### (4) 3D 平面直接抓取器（`DragPlaneRaycaster`）
* 当鼠标/手指（希沃白板触控）命中带有 `handleId` 的 3D 交互手柄（如透镜、磁场圆心、发射初速箭头、滑块位置）时：
  * 立即临时置 `controls.enabled = false` 锁止镜头旋转；
  * 将指针射线投射到当前物理约束平面（默认 $z = 0$ 或模型指定平面），实时换算物理坐标回传 `engine`；
  * 为触控大屏设置不可见扩大碰撞球（屏幕等效 $\ge 44\text{ px}$），确保手指一抓就准，松手后恢复镜头控制。

#### (5) WebGL 单例上下文池 + 教室核显性能守卫（`PerformanceGuard`）
* **单例铁律**：全应用仅创建 **唯一 1 个 `WebGLRenderer` + 唯一 1 个 `CSS2DRenderer`** 挂载于常驻宿主容器。跨 22 个 3D 模型切换时，严格递归 `dispose()` 旧 `THREE.Scene` 的所有 `Geometry`、`Material`、`Texture` 并清空 `CSS2DObject` DOM 节点，**绝不反复创建销毁 WebGL Context**，根除 16 上下文上限崩溃。
* **三级自适应画质与核显保护**：
  * 自动侦测帧耗时：若连续 $1.5\text{ s}$ 帧率 $< 28\text{ fps}$，自动从 `High`（$\text{dpr} \le 1.5$、软阴影、抗锯齿）平滑降档至 `Balanced`（$\text{dpr} = 1.0$、轻量化高光玻璃材质替代多遍折射）或 `ClassroomLite`（关闭实时阴影仅保留接地投影圆盘），保证老旧教室机稳定 $\ge 45\text{ fps}$。
  * **静止零耗电休眠**：当物理仿真处于暂停态且相机 `camera-controls` 触发 `rest` 事件后，自动挂起 3D 渲染循环，直至参数变更、点击拖拽或切拍时瞬时唤醒。
  * **不可逆 Context Lost 自动兜底**：监听 `webglcontextlost`，若教室电脑无硬件 WebGL2 或驱动崩溃，自动无报错回退到该单元既有 V2.0 高清 2D Canvas 渲染器，确保讲台永不黑屏。

### 2. 跨模型导演分镜、双屏控制台与“突发灵感快编器”（`packages/director-deck`）

#### (1) 一节课一部完整剧本：4 种节拍类型（彻底取代 PPT）
