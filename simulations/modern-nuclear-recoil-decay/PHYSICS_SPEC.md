# N03 / F05 核衰变反冲径迹与半衰期统计

## 1. 反冲轨迹（cloud-chamber-recoil）
- 静止母核、模型静质量（非核素实测数据）、点粒子、无能损及散射。α 模式为理想二体运动；β⁻ 模式只表达反中微子能量趋零的端点理想化，一般三体 β 衰变并无等大反向的电子和子核动量。
- 能量预算为 Q = Δm c² = K₁ + K₂；以相对论二体动量、稳定动能表达式、带符号匀强磁场和 Boris 数值轨迹求取几何。两个轨迹截段采用共同长度比例，采样相位而非同时刻。B=0 使用直线截段；不提供有限曲率半径或半径比。翻转 B 时轨迹镜像，半径不变。圆拟合失败不得用解析半径冒充拟合值。界面半径以 m 显示，标记尺寸与画面缩放非物理测量。
- α 端点示例同号轨迹外切；β⁻ 端点示例异号轨迹内切。这些几何结论均以理想端点条件为前提。
- 该模式为静态理想化比较，不使用课堂播放时间冒充微观时间。

## 2. 半衰期统计（half-life-mc）
- 初始 N₀ 个核由固定种子的 PRNG 一次独立抽取指数寿命，T = -T₁/₂ log(1-U)/ln 2。以实际经过时间和寿命阈值确定状态；固定参数与种子下相同时间的实现不因步长分割改变。
- 理论期望 E[N(t)] = N₀ 2^(-t/T₁/₂)，不是每次样本的精确数量。保留 t=0、全部真实样本衰变事件及末端游标；样本阶梯和理论曲线分开，计数非负且单调，归零不复活。
- 改参/切换模式重建独立样本。在线与离线真实时间、状态、读数和导出共享模型，不逐帧重新抽样。

## 3. 既有代际期望示意（chain-fission）
仅保留原有抽象数学比较，不扩展实际核装置或控制功能，不代表真实粒子轨迹、时间演化、运行安全或爆炸结论。与前两模式的观测量、公式、导出隔离。
