# M04 抛体运动与斜面/曲面耦合（`mech-projectile-coupling`）物理建模规范

- **微分方程**：
  - 真空平抛/斜抛：$\ddot{x}=0,\; \ddot{y}=-g$；
  - 二次空气阻力：$\ddot{\mathbf{r}} = \mathbf{g} - \frac{c_d}{m}\|\mathbf{v}\|\mathbf{v}$，由 RK4 高阶推进。
- **边界事件捕获**：`bisectEvent`（$|\Delta t| \le 10^{-8}\text{ s}$）精确捕获落入倾角为 $\theta$ 斜面 $y + x\tan\theta = 0$ 或半圆槽 $(x-R)^2 + y^2 - R^2 = 0$（仅下半圆） 的碰撞时刻与位置。
- **解析验证特征**：
  - 真空平抛落斜面飞行时间 $t_{\text{fly}} = \frac{2v_0\tan\theta}{g}$；
  - 任意发射角斜抛包络线（安全抛物线）$y_{\text{env}}(x) = \frac{v_0^2}{2g} - \frac{g}{2v_0^2}x^2$；
  - 速度反向延长线交于水平位移中点（平抛特性）。

## H20 物理边界、离散时间与适用域
发射点是左端原点；半圆槽圆心 (R,0)，有效槽壁仅为 x∈[0,2R]、y=−√[x(2R−x)] 的下半圆。上半圆不存在，不得捕获伪碰撞；从右槽口上方飞出时记录 escaped 而非 impact，不再模拟未定义区域。平地安全包络模式从地面水平发射时自由飞行时长为零。倾斜面或半圆槽的发射根 t=0 与后续回返根严格区分；先用不超过 1/240 s 的物理子步建立有效侧，必要时在首步寻找有效内点，再二分至 1e−9 s。无阻力采用解析位置和速度，有阻力 RK4 同一子步上限。终止返回 halt、实际 advancedTime 和唯一事件，保留撞前瞬时速度；再步进时间、状态、事件不变。虚线真空对照按同一时刻解析采样，不宣称其也发生相同的碰撞。此轮只改引擎和测试，图解、取景与导出另验。

## H21 课堂几何图解与读数
Canvas、SVG/TikZ 的 DiagramIR 共用同一物理坐标几何源：真实下半圆、斜面、真空安全包络、实际轨迹、同刻真空对照。水平真空发射且 t>0 时，速度反向延长至发射水平线的截点 x/2（用当前真实 x,y）；有阻力或非水平发射时不宣称中点性质。真空平抛到斜面，法向 n=(sinθ,cosθ)，d=x sinθ+y cosθ；t*=v₀tanθ/g，P*=(v₀t*,−gt*²/2)，足点 Q=P*−d_max n；最远点速度平行斜面、PQ 与斜面垂直。构造 P* 明确为理论点，不冒充当前质点。安全包络只画地面以上的 x∈[0,v₀²/g] 段，标为真空包络而非当前轨迹。实际速度箭头和初始速度箭头同帧比例，非真实长度；终止圈及事件标注明确撞击/飞出，保留撞前速度。当前仍采用模型既有 RK4 并限制子步（V2 总规格的 RK45 升级仍待专项验证，不能以 RK4 冒充）。
