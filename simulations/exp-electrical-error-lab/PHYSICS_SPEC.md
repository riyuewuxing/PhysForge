# X02 电学核心实验真误差仿真台（exp-electrical-error-lab）

全部电路测量均基于非理想 MNA（`solveNonlinearMna`）求解：
1. **测电源电动势与内阻（`emf-inner-outer`）**：
   - 电压表直接并接电源（相对外接分流，$I$ 漏流 $U/R_V$）：$E_{\text{测}} = \frac{R_V}{R_V + r} E < E,\quad r_{\text{测}} = \frac{r R_V}{r + R_V} < r$；
   - 电流表直接串联在电源旁（相对内接分压，$U_A = I R_A$）：$E_{\text{测}} = E,\quad r_{\text{测}} = r + R_A > r$；
   - 多挡负载电阻 MNA 实跑线性拟合斜率/截距与非理想解析值误差 $< 10^{-6}$。
2. **描绘小灯泡伏安特性（`bulb-iv-curve`）**：使用非线性幂律灯丝 `kind: 'lamp'` 跑分压/限流电路对比全压起点与非线性发热弯曲。
3. **半偏法测电流表内阻（`half-bias-rg`）**：非理想 MNA 精确求解半偏电阻箱读数 $R_2$，证明严格有 $R_{g,\text{测}} < R_{g,\text{真}}$，且随主干电阻 $R_1 \to \infty$ 收敛至真值。
4. **游标卡尺（10/20/50 分度）与螺旋测微器**：零漂移双向精准读数模型。


## F09 独立验收契约草稿（未运行、未改实现）
- 测电源两种接法按实际四节点拓扑校验，不只核对公式文字。节点 G=负端、P=理想电源正端、T=内阻后端、L=电流表后端；E 接 G-P，r 接 P-T，R_A 接 T-L，R_L 接 L-G。电压表直接并电源时 R_V 接 T-G；电流表串入电源时 R_V 接 L-G。导出线段连通关系应与 MNA 一致，不能用同一幅示意图代替。
- 电压表直接并电源：I 为负载支路电流，U=E-r(I+U/R_V)；电流表串入电源：I 为总电流，U=E-(r+R_A)I。测得值的拟合、真值、仪表参数应分开显示，不能把一种接法的公式在另一种接法中复用。
- 半偏法：保持 R1 不变，初始 I0=E/(R1+Rg)；并入 R2 后令 Ig=I0/2，严格得到 R2=R1*Rg/(R1+Rg)，与 MNA 数值比较。仅在 R1≫Rg 时近似为 Rg。不能用“偏小”符号代替定量校验。
- 灯泡模型 I=k*(|U|+1e-6)^(alpha-1)*U 为既有数值模型。分压滑片 0 与 1 的理想端点分别 U=0 与 U=E；限流端点 1 亦 U=E，另一端正电压。中间节点遵守 KCL；当前滑片值必须有独立求解的当前工作点，不能只展示固定十一点扫测或未经说明的插值。
- 游标卡尺 N=10/20/50、最小分度 1/N mm，量化误差为 |读数-目标长度|。游标线几何须满足 N 个游标分格对应 N-1 个主尺毫米；螺旋测微器固定尺含 0.5mm 线，可动尺 50 格、0.01mm/格，实际可读的刻度与数值一致。不同模式导出相应实验图，不得导出无关电路。此处只记录后续验收契约，F08 闭环前不推送、不运行。
