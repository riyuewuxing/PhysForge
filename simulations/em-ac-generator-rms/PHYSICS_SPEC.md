# E07 正弦交流电产生与有效值直观推导（em-ac-generator-rms）物理与数值规格书

## 1. 物理背景与课标对照
- 对应人教版《选择性必修二》第三章 第1、2节（交变电流的产生、中性面与垂直中性面、交流有效值的热量等效定义）。
- 核心方程：
  1. 发电机瞬时感应电动势：$e(t) = N B S \omega \sin(\omega t)$（$E_m = N B S \omega$），磁通量 $\Phi(t) = B S \cos(\omega t)$；
  2. 分段复合 Simpson 积分求任意周期波形 $u(t)$ 在周期 $T$ 内的精确有效值：
     $$U_{\text{rms}} = \sqrt{\frac{1}{T}\int_0^T u(t)^2\,\mathrm{d}t}$$
     针对半波整流、占空比方波、锯齿波等分段间断波形，先按间断点切分光滑子区间再施加 Simpson 积分，消除阶跃点 $O(1/N)$ 误差。
  3. 削峰填谷功率可视化：$p(t) = \frac{u(t)^2}{R}$ 瞬时功率曲线对比等面积矩形恒定平均功率 $P_{\text{avg}} = \frac{U_{\text{rms}}^2}{R}$。

## 2. 单元测试与精度卡点
1. 正弦波 ($U_m/\sqrt{2}$)、半波整流 ($U_m/2$)、全波整流 ($U_m/\sqrt{2}$)、占空比 $D$ 方波 ($U_m\sqrt{D}$)、锯齿波 ($U_m/\sqrt{3}$) 与直流偏置叠加波 ($\sqrt{U_{\text{dc}}^2 + U_m^2/2}$) 有效值数值积分误差均 `< 1e-6`；
2. 中性面 ($\theta = k\pi$) 处磁通最大而电动势为零，平均焦耳热累计 $Q(T) = \frac{U_{\text{rms}}^2}{R} T$ 吻合 `< 1e-6`；
3. 边界值（$\omega=0, B=0, dt=0$）无 `NaN` / `Infinity`。

## 3. H36 修订：解析区间热量与物理边界
- 固定参数段，取参考机械相位 x=ft mod 1；角 θ=2πft，磁通 Φ=BS cosθ 为单匝，磁链 NΦ，理想源 e=NBSω sinθ。整流器无压降/无储能；半波、全波分别采用 max(e,0)、|e|。方波、锯齿及直流偏置是独立教学波形，幅度以 E_m 作参数标定，不宣称由裸旋转线圈产生。
- 负载为纯电阻，u 为负载电压，i=u/R，p=u²/R；R 的 UI 正域不变。E_m 与负载最大绝对值分开，直流偏置不能冒称峰值 E_m。全波有效值以参考机械周期计算，其最小周期为 T/2；方波 D=0/1 和零频 DC 为恒值，零频无有限机械周期。
- 热量不用固定步 RK4 采样阶跃。将时间段拆为首段、整周期及尾段，解析积分 u²，除以 fR；f=0 时直接累积恒值 u²Δt/R。正弦平方原函数 x/2−sin(4πx)/(8π)，半波在 x=1/2 封顶，方波 min(x,D)，锯齿 4x³/3−2x²+x；DC+AC 保留交叉项。有效值仍保留独立分段 Simpson，与解析 RMS 交叉检验；累计热量与整个固定参数时间段独立比对，非恒等零残差。参数切换按工作台复位新实验，不宣称动态变频连续历史。
- 发电机仅在正弦/理想整流模式表示电磁力。采用水平 +x 磁场与绕竖直轴转动的方形线圈，图为斜投影；两条竖直边的真实安培力沿 ±z，画布箭头为投影分量，不把投影长度当全力。波形模式无假电磁力。
