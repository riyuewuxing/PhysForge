# B1 自由复合场建模器（`builder-composite-em-field`）物理建模规范

- **规范 ID**：`builder-composite-em-field`（兼容 V1.0 旧 ID：`em-bounded-magnetic-field`）
- **控制方程**：$\frac{d\mathbf{v}}{dt} = \frac{q}{m}(\mathbf{E} + \mathbf{v}\times\mathbf{B})$
- **数值推进**：V3.1 B1 改为分段常场的解析流映射（公共 Boris 推力器不变）；有界区域边界通过独立几何括区 + Signed Distance Function + `bisectEvent` 定位，分段推进全部余时。
- **V2 能力**：9 束平行光磁聚焦、斜入旋转圆/放缩圆/平移圆、配速法 $\mathbf{v}_d = \mathbf{E}\times\mathbf{B}/B^2$ 正交分解、逆问题临界半径求根 `solveCriticalSpeedForRadius`、直操手柄、Auto-FBD 洛伦兹力与电场力分解、随动参考系及黑白试卷 `DiagramIR`。

## V3.1 有限场域的真实事件与全时间推进
- 坐标 x 向右、y 向上、B_z>0 出纸面；场外直线运动；场内及全空间正交 E_y/B_z 均为分段常场，采用其解析流映射而非修改公共 Boris。所有时刻仍由真实状态推进，禁止装饰轨迹。
- 事件要求：端点同侧亦能检测真实穿越；直线按凸域相交区间寻找内部样本，磁场圆弧按坐标或径向极值分割以保证事件括区，再调用共享 bisectEvent（目标时间误差≤1e-8 s）。相切而无内外符号变化不记为穿越；精确步末接触可在下一步确认，事件时间仍为边界时刻。每次出入场后推进全部余时，粒子与全局时钟同步。
- 独立复现先行：矩形中性粒子一整步穿越两边界、半空间入射半圆出射后自由飞行、假设完整磁圆首尾同侧但首次离场、相切不穿越、四分之一周期位置/速度及整周期闭合、中性粒子无 E×B 漂移。旧 SHA 6180d81 的真实 CI 45533909135 新增5项失败、相切项通过；不降低旧断言。

- 令 ω=qB_z/m，a=qE_y/m，θ=ωΔt，S=sinθ/θ，C=(1−cosθ)/θ，H=(1−cosθ)/θ²，J=(θ−sinθ)/θ²。v_x'=v_x cosθ+v_y sinθ+aΔt C，v_y'=v_y cosθ−v_x sinθ+aΔt S；Δx=Δt(v_x S+v_y C)+aΔt²J，Δy=Δt(v_y S−v_x C)+aΔt²H。零 θ 极限 S=1,C=0,H=1/2,J=0；小角稳定计算。z 匀速。整周期相位真实；纯磁场守恒，交叉场电功 qE_yΔy=ΔK。中性粒子无磁回旋或电漂移；B=0 时保留电加速。
- 场外凸域直线取内部样本；圆形场内按径向距离极值分段、半空间/矩形按坐标极值分段；最多搜索一真实回旋周期。精确接触点以单侧运动判定（纯相切不记穿越）；二分 1e-10 s，接触轮廓只容忍浮点舍入量级误差。保护上限触发时显式报错而不丢弃余时。长步轨迹按实际解析状态采样，尾迹上限900点。

- 表示契约：B_z>0 为 ⊙、3D +z，B_z<0 为 ⊗、3D −z，B=0 不画磁场标记；全空间/半空间的可见截窗不冒充物理外壁。Canvas/Three/DiagramIR 共享实际轨迹与出入界点，导出不截断第6–9束。v_d 与 v_rot 首尾相接，合矢量为 v；场外 R 只作为若入场的理论半径。2D 投影深色语义色、主轨迹局部光晕和有界3D实点光芯不改变引擎。
