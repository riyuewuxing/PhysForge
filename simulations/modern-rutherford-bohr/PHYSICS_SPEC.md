# N02 卢瑟福 $\alpha$ 散射与玻尔氢原子能级跃迁（modern-rutherford-bohr）物理建模规格

## 1. 无量纲核物理缩放上下文（`ScaleContext`）
- $L_0 = 10^{-15}\ \text{m}\ (\text{fm}),\ T_0 = 10^{-22}\ \text{s},\ M_0 = m_\alpha = 6.6446573357\times 10^{-27}\ \text{kg},\ Q_0 = e$。
- 库仑排斥无量纲常数 $\kappa = \frac{k_e Z_1 Z_2 e^2}{E_0 L_0}$，运动方程 $\frac{d^2 \hat{\mathbf{r}}}{d\hat{t}^2} = \frac{\kappa}{\hat{r}^3}\hat{\mathbf{r}}$，由 `integrateAdaptiveRK45` 求解。
- 渐近解析对照：$\tan(\theta / 2) = \frac{k_e Z_1 Z_2 e^2}{2 K_\alpha b}$，机械能全程严格守恒（相对误差 $< 10^{-6}$），散射角相对误差 $< 10^{-4}$。

## 2. 玻尔氢原子能级（`mode = 'bohr'`）
- 能级公式：$E_n = -\frac{13.6}{n^2}\ \text{eV}$。
- 跃迁波长：$\lambda_{n_i \to n_f} = \frac{hc}{e |E_{n_i} - E_{n_f}|}$，通过 `wavelengthToRgb` 渲染巴耳末可见光谱线。
- 区别“单个受激原子”（级联跃迁最多 $n-1$ 条）与“一群受激原子”（$C_n^2 = \frac{n(n-1)}{2}$ 条）；区分光子共振吸收（须精确满足 $\Delta E$ 或电离）与电子碰撞非弹性激发（仅需 $E_e \ge \Delta E$，保留剩余动能）。

## H47 F04 独立复现目标（未验收）
- 经典固定重靶核点电荷近似，K 是无穷远 α 粒子动能；b 为有符号入射渐近线偏距。a=k_e Z₁Z₂e²/(2K)，r_min=a+√(a²+b²)，头碰 b=0 在入射负 x 侧 x=−2a 转回；不可穿核、伪造正侧终点、用粗采样最小值冒充最近点。低能大Z的最近点可超旧固定180 fm显示区域，取景必须随物理轨迹。保留独立数值积分对解析散射角及机械能的原有容差；额外检验全程与符号对称，不把同一个解析角重复当独立验证。
- 可见轨迹的世界点、核位置、渐近线、最近点与导出同源；核为点电荷模型，核半径/量子/靶核反冲未建模，不把相对绘图半径当真实核尺度。不使用无关能级求解或每帧重新求解完整轨迹。
- 氢原子 n-only 近似能级 −13.6/n² eV。ensemble 全部可选对；single-atom 仅展示一种最大条数的逐级级联 n→n−1→…→1，不宣称同一原子发出 C(n,2) 或所有 Balmer 线，不假设各跃迁同概率。显示全选定能级与实际光谱，区分可见范围及 UV/IR。
- 基态探针与发光初始 n 分开：光子理想共振使用明确 ±0.005 eV 两位小数输入容差（数值输入约定，不是实际谱线线宽）；未达激发的电子在忽略弹性反冲的模型中保留原动能。电子碰撞选择能量允许的最高已建模能级（仅示例，不代表实际分支概率）。电离不返回离散 n；光电离超阈能量为电子动能（固定核近似），电子撞击电离只能确定电子总剩余动能，不能指定一个电子分配。两模式数据隔离、真实参数与示意时间/物理时间明确区分。
