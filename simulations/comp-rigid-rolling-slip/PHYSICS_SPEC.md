# C01 刚体定轴转动与滑滚转换（comp-rigid-rolling-slip）

## 1. 刚体转动惯量谱（$I = c m R^2$）
- 实心球 $c=2/5$、空心薄球壳 $c=2/3$、实心圆柱 $c=1/2$、薄圆环 $c=1$。

## 2. 水平滑动→纯滚动杂交自动机（`HybridAutomaton` + `bisectEvent`）
- 触地相对滑移速度 $v_{\text{slip}} = v - \omega R$；纯滚动守恒与临界事件二分至 $|\Delta t| \le 10^{-8}\text{ s}$。
- 当 $\omega_0 = 0, v_0 > 0$ 时，实心球严格满足：$t_c = \frac{2 v_0}{7 \mu_k g},\quad v_c = \frac{5}{7} v_0$（误差 $< 10^{-6}$）；支持初速度带强烈回旋反旋的保龄球回滚反物理演示。

## 3. 四刚体斜面纯滚竞速（`incline-race`）
- 加速度 $a = \frac{g\sin\theta}{1 + c}$，机械能守恒漂移 $< 10^{-6}$，四刚体同坡道冲刺实心球最快、薄圆环最慢。

## 4. H59 后续候选验收设计（未执行，不代表已修复）

- 符号约定：沿水平向右或沿斜面下坡为正，顺滚方向的角速度为正，接触点切向相对速度 $u=v-R\omega$。滑动时 $f=-\mu_kmg\,\operatorname{sgn}(u)$（水平），$m\dot v=f$，$I\dot\omega=-Rf$。
- 独立解析基准：$t_c=|u_0|/[\mu_k g(1+1/c)]$，$v_c=(v_0+cR\omega_0)/(1+c)$，$mRv+I\omega$ 恒定，$E_0-E_c=mc u_0^2/[2(1+c)]$；转换后的剩余步长必须以纯滚动速度传播，机械能不应继续损失。覆盖四种形状、正负滑移、倒旋回滚和近零滑移。
- 斜面纯滚条件：$f_s=-[c/(1+c)]mg\sin\theta$，故至少需要 $\mu_s\ge[c/(1+c)]\tan\theta$。现有参数仅有 $\mu_k$，不得静默当成 $\mu_s$；若继续采用理想纯滚动竞速，应明确其静摩擦充足前提，不能画出被任意限幅但与加速度不一致的静摩擦。是否扩展成有限静摩擦滑滚竞速，留待后续实际施工决定。
