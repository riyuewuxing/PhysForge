# T02 热力学循环与分子动理论微观盒（thermo-cycles-kinetic-md）物理与数值规格书

## 1. 物理背景与课标对照
- 对应人教版《选择性必修三》第一章《分子动理论》（布朗运动、气体分子速率统计麦克斯韦分布、气体压强微观解释）与第三章《热力学定律》（第一/二定律、卡诺循环与矩形循环效率）。
- 核心方法：
  1. **封闭热力学循环 (`cycle-carnot`, `cycle-rect-pv`)**：
     - 四段解析求取做功 $W_i$、吸放热 $Q_i$、内能变 $\Delta U_i$ 与循环效率 $\eta = \sum W_i / \sum_{Q_i>0} Q_i$，对照卡诺理想效率上限 $\eta_C = 1 - T_C / T_H$。
  2. **二维空间哈希硬盘 MD 与布朗运动 (`kinetic-md-box`)**：
     - 严格禁用 `Math.random()`，采用 `@physforge/physics-core` 的确定性 `createSeededPrng(seed)` 在无重叠晶格上初始化 $N \in [100, 400]$ 个弹性硬球分子（及可选大质量布朗花粉微粒）；
     - 有界子步调用 `SpatialHash2D.resolveDiskCollisions(particles, 1.0)`（邻域离散弹性碰撞与有限迭代去重叠），器壁弹性反射累计冲量并统计二维平均壁压 $P_{\text{wall}}$。

## 2. 单元测试与精度卡点
1. 卡诺与矩形封闭循环满足 $|\sum\Delta U_i| < 10^{-10}\text{ J}$ 且 $|\sum Q_i - \sum W_i| < 10^{-8}\text{ J}$；
2. 绝热硬球盒连续推进 **1000 步**：约化总动能相对漂移 `< 1e-8`；
3. $N=300$ 分子弛豫后速率分布与拟合的二维麦克斯韦分布 $F(v) = 1 - \exp(-v^2 / v_{\text{rms}}^2)$ 的历史确定性 CDF 距离回归阈值（$D_{300} < 1.36/\sqrt{300}$）；
4. 参数边界（`dt=0`, `seed` 复现）一致无 `NaN`。

## H45 修订候选（以真实同 SHA 验证为准）
- 卡诺/矩形循环是静态解析路径而非时序动画，不能同时生成无关粒子、推进虚假时间或暴露无关 MD 数据。卡诺合法域 T_H>T_C>0、r_V>1、n>0；不静默改写交叉温度，非法请求显示无有效循环且不给出效率。矩形最低温 T_A=T_C，实际最高温由压强比与体积比决定，T_H 控件不适用；热效率 W_net/Q_in，与同温区可逆上限比较，不把矩形称作两热源可逆机。
- 单原子三维理想气体热力学 C_V=3R/2 与二维硬盘微观模型分开。MD 使用约化长度、质量、时间单位；能量和二维压强不标 SI J/Pa，速率倍率与初始温度代理平方关系，不将其称为温度倍率。无热浴，不展示热机效率。
- 确定性无重叠初始化必须严格放置 N 个气体圆盘，另可选一个重粒子；真实粒子数、能量、统计样本必须一致。网格邻域须覆盖最大相互作用直径。公开步长可大于最小安全内部步长，按实际最大速率限制位移；不宣称离散重叠修正是连续精确事件解。墙碰撞保持弹性、计入冲量且处理多次反射及碰撞修正后边界。二维平均壁压=sum normal impulse/(4L×累计测量时间)，初态尚未测量；区别单步脉动、长时间平均和理想气体近似，不假定有限密度硬盘严格服从理想气体定律。保持总动能，核对孤立等质量/异质量碰撞与长步墙冲量。
- 二维速率分布使用气体样本（排除花粉），以同一样本二阶矩拟合的 CDF 仅为描述性偏差 D，不将已拟合参数的固定 KS 临界值当有效显著性检验；直方图须包含全部样本且明确横轴、分箱与归一化，避免把尾部压入最后普通区间。

- 细化步长：每次子步最大自由飞行位移 ≤ r_gas/4；每次子步按当前最大实际速度重新定步长，单步预算上限 10000，超出报错不静默截断。最大接触直径 2r_pollen 作为网格边长；至多三次局部弹性冲量/去重叠与反射壁约束迭代。记录末态最大重叠深度，不以动能守恒冒充无穿透证明。多体密集同时接触的精确事件解仍未实现。
