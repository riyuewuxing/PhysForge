# M08 含弹簧连接体与临界分离模型（`mech-spring-separation`）物理建模规范

- **坐标系与控制方程**：沿光滑斜面（倾角 $\theta \in [0, 45^\circ]$，水平面取 $0^\circ$）向上为正 $s$ 轴，弹簧固定在左侧底座，原长平衡位置处为 $s = 0$，初始压缩至 $s_0 < 0$；物块 $m_1$（与弹簧拴接）和物块 $m_2$（单边贴合接触，不粘连），右侧可选外力 $F_{\text{ext}}$ 拉 $m_2$。
  - **共动相（$F_N > 0$）**：$(m_1+m_2)a = -ks + F_{\text{ext}} - (m_1+m_2)g\sin\theta$，两体间弹力 $F_N = \frac{m_2}{m_1+m_2}(-ks) - \frac{m_1}{m_1+m_2}F_{\text{ext}}$（当 $F_{\text{ext}}=0$ 时恰在原长 $s=0$ 处 $F_N=0$ 分离）。
  - **临界分离检测**：使用 `bisectEvent`（$|\Delta t| \le 10^{-8}\text{ s}$）精确锁定 $F_N = 0$ 时刻与分离位置，进入自由分离相：$m_1$ 受弹簧单独作用简谐振动，$m_2$ 以 $a_2 = F_{\text{ext}}/m_2 - g\sin\theta$ 独立运动。
- **积分器**：全程采用 `stepVelocityVerlet` 对称辛积分，无外力时全系统机械能漂移 $< 10^{-6}$。
