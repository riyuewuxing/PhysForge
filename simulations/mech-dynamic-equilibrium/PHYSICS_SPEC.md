# M02 动态平衡几何图解（mech-dynamic-equilibrium）

准静态参数演示，不积分动力学；t 是演示时间。x 向右、y 向上，G=(0,-mg)，g=CLASSROOM_GRAVITY。可解时 F1+F2+G=0，真实向量残差 < 1e-10 N。绳只能受拉；不可行或数值奇异构型无可显示的可靠有限平衡解，禁止负张力、替代行列式、强制闭合箭头。无解态内部零力为未求解占位，不是测得的零张力，遥测省略未知力并显式标记。

1. 活结对称理想轻滑轮：两绳与水平成 θ，T1=T2=mg/(2 sinθ)，方向 (-cosθ,sinθ)、(cosθ,sinθ)。θ=10°–85°，理论下界 mg/2（90°极限）。
2. 死结：左绳与**竖直**成 α=15°–75°，右绳相对水平 β=-30°–75°。u1=(-sinα,cosα)、u2=(cosβ,sinβ)，T1=mg cosβ/cos(α−β)，T2=mg sinα/cos(α−β)。有限正张力要求 cos(α−β)>0；cos≈0 时数值奇异，不能替换。β=α 时右绳垂直左绳，T2,min=mg sinα，不是 cosα。近奇异若浮点残差达不到既定容限，报告不可可靠求解，不改变容限。
3. 历史 key hemisphere-similar：保留已有水平拉力/光滑斜面法向示意。θ 为法向相对竖直向左角，N=mg/cosθ、T=mg tanθ；θ=10°–75°。法向和水平力不是同一个方向，显示切面及独立法向角手柄，不声称是顶端悬绳半球。
4. 新 key hemisphere-suspension：真正光滑半球上点状物块。球心 O=(0,0)，接触 P=(-R sinθ,R cosθ)，悬点 S=(0,R+h)，R>0、h>0，θ=1° 至外切上界（见下文）。N 沿 OP，T 沿 PS，OP+PS=OS。由相似性 N=(mg/(R+h)) OP、T=(mg/(R+h)) PS；N=mg R/(R+h) 恒定（固定 R,h,m），T=mg |PS|/(R+h)，下确界 mg h/(R+h) 为 θ→0⁺ 连续极限。实际 R、h、绳长及接触位置同源，非水平拉力模型。

自动扫描用各模式有限角域的相位正弦函数，t=0 精确从选定构型出发，连续变化；不可行角域允许作为反例而非假平衡。dt=0 保留状态。角度、受力、手柄、受力三角形和 DiagramIR 同源；三角形逐段累加真实力，最后一箭头不强闭合。力箭头统一比例且随当前最大力缩放（非跨帧绝对长度固定），绳/支承几何与力尺度分开。

### 实体半球接触域
直绳段 PS 必须位于球面外侧，故 OP·PS ≥ 0，即 cosθ ≥ R/(R+h)。界面上界取 floor(arccos(R/(R+h))·180/π) 度，向下取整避免穿模；下界 1°，因为 θ=0 时 N、T 共线，只能确定 N+T=mg，力分配不唯一。mgR/(R+h) 与 mgh/(R+h) 在球顶仅是 θ→0⁺ 的连续极限，不宣称唯一静力解。
