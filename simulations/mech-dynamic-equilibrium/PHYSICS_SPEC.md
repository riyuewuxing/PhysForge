# M02 动态平衡几何图解（mech-dynamic-equilibrium）

准静态参数演示，不积分动力学；t 是演示时间。x 向右、y 向上，G=(0,-mg)，g=CLASSROOM_GRAVITY。可解时 F1+F2+G=0，真实向量残差 < 1e-10 N。绳只能受拉；不可行或数值奇异构型无可显示的可靠有限平衡解，禁止负张力、替代行列式、强制闭合箭头。无解态内部零力为未求解占位，不是测得的零张力，遥测省略未知力并显式标记。

1. 活结对称理想轻滑轮：两绳与水平成 θ，T1=T2=mg/(2 sinθ)，方向 (-cosθ,sinθ)、(cosθ,sinθ)。θ=10°–85°，理论下界 mg/2（90°极限）。
2. 死结：左绳与**竖直**成 α=15°–75°，右绳相对水平 β=-30°–75°。u1=(-sinα,cosα)、u2=(cosβ,sinβ)，T1=mg cosβ/cos(α−β)，T2=mg sinα/cos(α−β)。有限正张力要求 cos(α−β)>0；cos≈0 时数值奇异，不能替换。β=α 时右绳垂直左绳，T2,min=mg sinα，不是 cosα。近奇异若浮点残差达不到既定容限，报告不可可靠求解，不改变容限。
3. 历史 key hemisphere-similar：保留已有水平拉力/光滑斜面法向示意。θ 为法向相对竖直向左角，N=mg/cosθ、T=mg tanθ；θ=10°–75°。法向和水平力不是同一个方向，显示切面及独立法向角手柄，不声称是顶端悬绳半球。
4. 新 key hemisphere-suspension：真正光滑半球上点状物块。球心 O=(0,0)，接触 P=(-R sinθ,R cosθ)，悬点 S=(0,R+h)，R>0、h>0，θ=1° 至外切上界（见下文）。N 沿 OP，T 沿 PS，OP+PS=OS。由相似性 N=(mg/(R+h)) OP、T=(mg/(R+h)) PS；N=mg R/(R+h) 恒定（固定 R,h,m），T=mg |PS|/(R+h)，下确界 mg h/(R+h) 为 θ→0⁺ 连续极限。实际 R、h、绳长及接触位置同源，非水平拉力模型。

自动扫描用各模式有限角域的相位正弦函数，t=0 精确从选定构型出发，连续变化；不可行角域允许作为反例而非假平衡。dt=0 保留状态。角度、受力、手柄、受力三角形和 DiagramIR 同源；三角形逐段累加真实力，最后一箭头不强闭合。力箭头统一比例且随当前最大力缩放（非跨帧绝对长度固定），绳/支承几何与力尺度分开。

### 实体半球接触域
直绳段 PS 必须位于球面外侧，故 OP·PS ≥ 0，即 cosθ ≥ R/(R+h)。界面上界取 floor(arccos(R/(R+h))·180/π) 度，向下取整避免穿模；下界 1°，因为 θ=0 时 N、T 共线，只能确定 N+T=mg，力分配不唯一。mgR/(R+h) 与 mgh/(R+h) 在球顶仅是 θ→0⁺ 的连续极限，不宣称唯一静力解。

### 动杆与定杆：明确系统、支承和符号
两种新模式的端点 P=(0,0)，杆长 L，支点 O=P-Lu，u=(cosα,sinα)，α=15°–75°（相对水平）；绳由 P 指向 v=(-cosβ,sinβ)，β=-30°–150°（从左水平朝上计角）。角度为可调整的准静态构型，不将实际转动过程当成平衡。杆无重、绳轻、端点载荷 G=(0,-W)，W=mg；在每一构型以端点受力或整体支承平衡求解。

5. 动杆 hinged-rod：理想两端铰接二力杆；有符号轴力 C 沿 O→P 为正（受压），负值为受拉。C u+T v+G=0；D=sin(α+β)，T=W cosα/D，C=W cosβ/D。仅 D>0 才有非负绳张力；D≈0 无有限解；C可正、负、零，不把杆受拉当作绳受压。T_min=W cosα 于 β=90°−α，力和力矩真实残差保持原阈值。
6. 定杆 fixed-rod：理想无重刚性杆在 O 固支，P 点绳张力 T0 由参数指定（非负，0–40 N），故 R=(T0 cosβ,W−T0 sinβ) 为固定杆作用于点载荷的力，也为固支作用于整体的合力；不限制 R 沿杆。外载合力作用于 P，整体支座力矩 M_O= (P−O)×R=L(cosα R_y−sinα R_x)，正为逆时针。独立核算 ΣM_O=M_O+(P−O)×(Tv+G)=0。固定杆在指定 T0 下无“最小拉力优化”读数；支座力矩不是第三个平面力矢量。零张力表示绳松弛的极限，图中不画有张力的箭头。

两模式共用端点坐标、绳方向、支座几何、实际力值、FBD 与 DiagramIR；固定支座力矩单独以 N·m 读数与符号展示，不以 N 标注。该构型是满足规格的明确理想化实例，不宣称覆盖所有动杆/定杆变式。

### 三视图及力—角度函数
默认保留真实力三角形；可独立选择辅助圆图层（死结/动杆），或选择优先显示的力—角度函数图层，不重置运行。辅助圆位于力空间，B=-G，A 为 B 到固定力方向直线的垂足；OA·AB=0，A 在直径 OB 的圆上，AB 对应最小绳拉力。其构型不冒充当前受力箭头。半球原结构的 OP+PS=OS 展示真实相似三角形。
角度函数使用同一代数求解器对合法角度每1°采样，并插入精确奇异点和极小点；无解值为 null，曲线分段断开，横轴是实际角 β/θ（度）而非演示时间。标记当前角与实际力，纵轴单位 N，定杆图显示 |R| 与指定 T，动杆图显示 |C| 与 T（轴力正负另行读数），半球图显示 N 和 T。打印 DiagramIR 追加同源的角度图和适用的辅助圆构造。初始请求、限幅后的初始角、当前实际角分别记录。

### 图解可读性
符号公式使用分行排版以保留完整等式，力箭头标签优先沿垂直方向偏移；定杆支座力偶是自由力矩，以支点附近独立圆弧及关联虚线表达，不穿过杆轴。在线拖拽以实际画布变换验证，离线优先显示视图开关与紧凑预设。物理求解、单位和阈值不变。
