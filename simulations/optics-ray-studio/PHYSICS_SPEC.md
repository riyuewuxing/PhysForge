# B3 自由几何光学建模器（`builder-optics-ray`）物理建模规范

- **规范 ID**：`builder-optics-ray`（兼容 V1.0 旧 ID：`optics-ray-studio`）
- **核心算法**：基于 `refractVector2D` 的多级界面斯涅尔矢量折射与全反射判据（$\sin\theta_t = \frac{n_1}{n_2}\sin\theta_i \ge 1$）、平行玻璃砖侧移 $\Delta x = d\frac{\sin(\theta_1-\theta_2)}{\cos\theta_2}$、三棱镜柯西色散光谱、光纤连续多次反射、双缝干涉 $\Delta x = \frac{L}{d}\lambda$，以及理想薄凸透镜高斯公式 $\frac{1}{u}+\frac{1}{v}=\frac{1}{f}$ 与虚像延长虚线。
- **V2 能力**：`ControlHandle` 入射角 / 物距直操拖拽、`SceneDSL` 序列化及 `DiagramIR` 黑白光路图输出。

## V3.1 H2 界面功率契约
- 对无吸收、非磁性均匀介质界面的非偏振光，功率反射率 R=(r_s²+r_p²)/2，透射率 T=1−R。斜入射使用 Fresnel 公式。显示百分比来自真实 R/T，光晕明暗经感知压缩以可读，不是线性光强计；颜色区分光路角色，不是波长改变。相同折射率时 R=0，不绘制虚假反射线。
- 临界角等号为极限掠射、法向传播功率为零；不声称不存在倏逝场。临界角仅 n₁>n₂ 时定义。此契约仅针对 tir-interface，不替代其他五子模式的独立验收。

## V3.1 H9 其余模式物理契约（第一阶段）
- 平行玻璃砖：空气—玻璃—空气，两无限平行平面在有限窗口内展示。主透射光忽略内部多次反射，保留非偏振入射 s/p 两分量经双界面透射后的平均功率，非伪造固定 95%。侧移是两平行射线的垂距。
- 三棱镜：等腰三角形三条有限边（含底面），取最近正向交点，真实 Snell 折射/反射；只追踪主要传播路径，部分反射支路不画。TIR 在棱镜内部继续至实际下一边；最多24次碰壁，不虚构出射。示例 Cauchy n(λ)=n_黄+0.016(n_黄−1)[1/λ²−1/(0.589 μm)²]，λ 用 μm；非真实玻璃牌号。仅黄光直接穿两腰时定义其偏向角，其他情况不输出伪零值。
- 光纤：空气端面入射、直纤芯/包层界面，严格用原 n₁/n₂ 与 θ₁=0；n₁>n₂ 才有临界角及空气接受角 asin(min(1,√(n₁²−n₂²)))。轴向传播不等于发生了反射；isTotalInternalReflection 在此模式代表满足侧壁导光条件。有限长度路径至侧壁或端面，漏光绘至包层，不继续假装导光；最多64段，不画部分反射分支。仅几何光学路径，不是波导模式、真实光强或微米尺寸。
- 理想薄凸透镜：近轴模型，v=uf/(u−f)，m=−v/u；u=f 时两条出射主光线平行，像在无穷远，不输出有限像距或倍率。实际光线分为入射和透镜平面出射，虚像反向延长从透镜平面起画；展示窗口裁切真实方向，不钳造像距。静态示意坐标保留真实长度比。
- 双缝：等幅同相相干窄缝、近轴归一化 I/Imax=cos²(πy/Δx)，Δx=Lλ/d；不建模单缝衍射包络、近场或绝对光强。图示装置与屏面读数比例分离。

- H9 第二阶段：五模式 Canvas 与 DiagramIR 复用同一 world geometry；透镜虚线不带传播箭头，焦平面显示无有限像，超出有限窗口的像不钳造。双缝屏面固定 ±4 mm，曲线与屏条使用同一 1201 个归一化采样，装置示意比例与屏面定量刻度分离。光学参数面板按模式显示，拖拽锚在真实入射光起点，不给双缝虚假入射角手柄。

- 实机门禁：玻璃砖侧移、棱镜直接黄光偏向角、光纤接受角及无导光条件、双缝λ变更、凸透镜实像/虚像/焦平面、投影模式与断网切片验证。光纤只画第一段包层光路至有限展示窗口，不模拟外包层边界后续传播。

- 真实 H9 双缝原图发现普通标签避让导致0 mm文字离开真实刻度。定量坐标刻度改为固定锚点，屏面与曲线采用共享SLIT_SCREEN几何，增加I/Imax=0/1标记；普通注释仍可避让。此处不改变实际物理采样。

## H67 B3 展示层与独立切片构图契约
- 全反射界面仍是两个半空间的有限显示窗口，不把金标准概念图的矩形外缘当作额外折射界面。上层玻璃感、下层柔和衰减和交点晕光纯属材质装饰；唯一真实界面是 y=0。
- 暖/冷光束使用原状态的起终点、方向和功率。多层发光与窄高光不改变斯涅尔角度、交点或功率，不画零功率光束。深色主题光晕按功率单调压缩；投影主题保持高对比。箭头是方向标识而非电磁场振幅。
- 单文件切片的画布已由布局排除右侧参数栏，B3 六模式使用实际画布宽高居中，不再二次预留在线悬浮检查器。非界面模式取原共享 scene bounds，比例等方；在线默认相机、拖拽锚点、引擎、DiagramIR 均不改动。
- 独立实机门禁直接捕捉 Canvas 线段与文字，验证临界角前后、法向、掠入射、等折射率、逆向介质的方向、功率、碰撞避让和独立画布居中。不是仅依据 DOM 读数或截图存在性。

## H73 旗舰展示层
- 深色界面上层材质提高连续玻璃区域的色彩与透光感，保留顶部柔和过渡及唯一真实 y=0 折射界面；不增加额外折射面、光线、虚构介质边界或几何变换。投影模式依然保持淡色背景和深色光线。
- 临界角的数值直接写入同一 Snell 公式卡的临界角关系，取自实际状态；n₁≤n₂ 明示无临界角而非零度。所有角度、Fresnel 功率及 DiagramIR 不变。
