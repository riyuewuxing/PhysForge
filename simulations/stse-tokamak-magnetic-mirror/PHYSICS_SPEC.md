# S01 托卡马克环形磁场与磁镜/磁瓶（stse-tokamak-magnetic-mirror）

## 1. 无散度 3D 磁镜场（$\nabla\cdot\mathbf{B} = 0$）与绝热不变量 $\mu$
- 轴对称磁瓶场强（柱坐标无散解析构型）：
  $$B_x = -B_0 \frac{x z}{L^2},\quad B_y = -B_0 \frac{y z}{L^2},\quad B_z = B_0\left(1 + \frac{z^2}{L^2}\right)$$
  恒满足 $\nabla\cdot\mathbf{B} \equiv 0$。
- 磁矩绝热不变量：$\mu = \frac{m v_\perp^2}{2 B}$；镜比 $R_m = 1 + z_{\text{coil}}^2 / L^2$，逃逸锥临界角 $\sin\theta_c = 1 / \sqrt{R_m}$。
- 数值积分采用 3D `stepBorisPusher`（纯磁场动能严格守恒 $< 10^{-8}$），$\theta > \theta_c$ 时粒子在磁喉前往复反射，$\theta < \theta_c$ 时穿透磁镜逃逸；且 $\mu$ 相对波动 $< 5\%$。

## 2. 托卡马克环形与极向螺旋场（`mode = 'tokamak'`）
- 大半径 $R_0$、环向场 $B_\phi \propto 1/R$ 与安全因子 $q$ 控制的极向场叠加形成螺旋磁面，懒加载 Vanilla `three` 视图展示 3D 磁感线与约束轨线。

## V3.1 S01 回归目标（先验收红灯）
- 投射角是初速度与初始位置处**总磁场**夹角，速率严格为 v0；托卡马克坐标系中不得把环向分量直接当平行分量。
- 镜场磁通线满足 r sqrt(1+z²/L²)=常量；环场 rho=sqrt((R−R0)²+z²)=常量，dθ/dφ=R/(qR0)。原 q 为极向强度控制参数，有限小半径面实际绕行比 q_eff=qR0/sqrt(R0²−rho²)，不冒充真实安全因子剖面。R≥0.15m 的解析适用域与磁轴附近的外推需区分。
- 真实事件：磁镜反射用沿局部 B 的平行速度过零，并用公共二分定位；磁喉首次越界用 |z|−zc，精度 1e-7s 以内；不施加人为速度反转、不截断剩余时间。保留既有动能、磁矩门禁与逃逸锥绝热近似。
- 这是教学尺度单带电粒子与给定外磁场，不含自洽等离子体、碰撞、真实线圈求解、输运、MHD平衡或聚变达成判定。
- 实现采用局部磁回旋相位上限 0.12 rad 的子步控制（原 0.0008 s 上限保留），Boris 无电场严格保速，临界事件仅观测、不施加重置冲量。出界为首次诊断面穿越，之后仍在数学延拓场中推进；磁矩最大偏差只统计出界前。托卡马克 0.55 m 小半径为示意诊断面，不模拟真实壁吸收。几何线使用镜场解析 flux 与固定 rho 的 RK4 极角积分，非零散欧拉拼接。动能和磁矩字段历史命名保留，数值是每单位质量。
- 旧测试的反射计数语义纠偏（b271865 CI45542909369 的两个失败，未降低原能量/磁矩容差）：52°标准磁瓶的绝热近似 bounce 角频率 v0 sinθ/L，首反射约1.1960 s、第二约3.588 s。独立 SciPy solve_ivp(RK45 默认,rtol=1e-10,atol=1e-12,max_step=.001)，直接积分 dr/dt=v、dv/dt=(q/m)v×B，并以 v·B/|B|=0 定位，得到 1.19564781 s、3.58694310 s，z=0.93639258 m、−0.93651151 m，五秒无磁喉穿越。旧3秒至少2次是 vz 回旋反号的误计数；现要求3秒恰1次，并以5秒恰2次、独立时刻及位置误差<0.005验算。事件二分精度和积分误差分别验证。
