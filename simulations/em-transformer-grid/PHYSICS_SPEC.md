# E08 理想变压器动态分析与远距离输电（em-transformer-grid）物理与数值规格书

## 1. 物理背景与课标对照
- 对应人教版《选择性必修二》第三章 第3、4节（理想变压器电压/电流/功率关系、原线圈串联等效电阻动态分析、高压远距离输电损耗与多用户开关动态调节）。
- 核心方程：
  1. **多路副线圈含原边电阻 $R_0$ 联立求解（`multi-tap-transformer`）**：
     $$\frac{U_2}{U_1} = \frac{n_2}{n_1}, \quad \frac{U_3}{U_1} = \frac{n_3}{n_1}, \quad U_1 I_1 = U_2 I_2 + U_3 I_3, \quad U_0 = U_1 + I_1 R_0$$
     等效输入电阻 $R_{\text{eq}} = \left(\frac{1}{n_1^2}\sum_{k=2}^3 \frac{n_k^2}{R_k}\right)^{-1}$。开关合上增加并联用户或减小 $R_2$ 时，通过比较明确的参数基准状态自动标出各电表升降箭头 $\uparrow / \downarrow$。
  2. **远距离高压输电链（`long-distance-grid`）**：
     - 发电机输出功率 $P_{\text{gen}}$、端电压 $U_{\text{gen}}$ $\to$ 升压变压器（升压比 $k_1$）$U_{\text{high}} = k_1 U_{\text{gen}}$、$I_{\text{line}} = P_{\text{gen}} / U_{\text{high}}$ $\to$ 输电线压降 $\Delta U = I_{\text{line}} R_{\text{line}}$、线损 $\Delta P = I_{\text{line}}^2 R_{\text{line}} \propto 1/k_1^2$ $\to$ 降压变至用户电网。

## 2. 单元测试与精度卡点
1. 多路副线圈稳态平均功率守恒 $|\sum U_k I_k - U_1 I_1| / (U_1 I_1) < 10^{-10}$；
2. 等功率输电条件下升压比翻倍，输电线损耗严格降至原值的 `1/4`（误差 `< 1e-10`）；
3. 边界条件（负载断开/功率为零、`dt=0`）无 `NaN` / `Infinity`。

## 3. H37 账本和可行域纠偏
- 全部电压、电流均为稳态有效值，纯阻负载、理想变压器、功率因数 1。不是交流暂态仿真；时间仅为可选示意动画。
- 多副线圈中 G₂=N用户/R₂（可为 0），断开副路 3 时 G₃=0 但其感应端电压不消失。明确区分电源 P₀=U₀I₁、原边 P₁=U₁I₁、副边 P₂+P₃，R₀ 损耗 I₁²R₀；系统效率 P用户/P₀；零输入时未定义（内部有限数值哨兵，界面显示 —）。
- 输电固定送端功率 P 与 U送=kU₀，I=P/U送；受端 U受=U送−IR。无源受端要求 P≤U送²/R（R=0 不设有限上限）。超界为无工作点，禁止将线损 min(P,I²R) 或假造 0 V 受端；请求量与实际量分离，无效工作点的内部有限数值哨兵不展示为实测。等号为短路极限，受端功率零，不能宣称有 220 V 母线。
- 有正受端电压时，以理想可调匝比变压器保持 220 V，明确非固定降压比；P用户=U受I，ΔP=I²R。保持 P、U₀、R，比较可行工况内 k 翻倍的线损 1/4。固定功率不是固定用户电阻。
- 守恒审计读取传入的 actual state.current，而非重新解方程覆盖坏数据；无效工作点应报告失败。基准固定为断开副路3、指定基准并联数，或同请求下 k=10；基准不可行时不显示误导趋势。

- 无解时公开观测量只包含请求参数与有效性状态，不发布实际电流/功率的内部哨兵；效率未定义时公开观测量不包含效率字段，避免通用参数扫描、CSV 和 AI 把 0 当成物理测量值。
