# W02 2D 波动池 FDTD 衍射、折射与干涉（wave-2d-ripple-fdtd）物理与数值规格书

## 1. 物理背景与课标对照
- 对应人教版《选择性必修一》第三章 第5节《波的衍射、干涉与多普勒效应》与《选择性必修一》第四章（惠更斯原理与折射波形弯曲）。
- 核心方程：
  $$\frac{\partial^2 u}{\partial t^2} = c(x, y)^2 \left(\frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2}\right)$$
  - 采用 `@physforge/physics-core` 的 `WaveFDTD2D`（`200 × 150` `Float32Array` 三缓冲五点差分 + `16` 格指数衰减吸收海绵层）；
  - **CFL 稳定性硬性钳位**：给定波速 $c_0$ 与空间步长 $\Delta x$，强制限制时间步长使柯朗数 $r = \frac{c_0 \Delta t}{\Delta x} \le 0.45 < \frac{1}{\sqrt{2}}$；
  - 支持双缝干涉（接收屏时间平均波强 $\langle u^2(y) \rangle$）、单缝衍射、障碍物绕射及非均匀折射率介质 $c(x, y) = c_0 / n(x, y)$ 折射聚焦。

## 2. 单元测试与精度卡点
1. 强制验证 CFL 数 `< 0.5`，连续推进 **2000 步**后全场无任何 `NaN` / `Infinity` 或指数发散；
2. 双缝干涉接收屏时间平均强度极大值间距 $\Delta y$ 与远场解析公式 $\frac{L}{d}\lambda$ 偏差 `< 5%`；
3. 边界条件（振幅为 0、`dt=0`）无 `NaN`。

## H41 时间、边界与测量修订
- 固定内部步长 1/240 s（若超出 CFL 则再整数细分），仅在累计请求时间跨过内部步时计算；t 为请求的物理时刻，fieldTime=stepsRun·h 为实际已求解场时刻，非整数时间余量显式可读，不强行推进或截断。连续调用和任意分割在同一内部时刻应一致。
- 历史状态保留当前及上一网格的不可变快照，内部三缓冲 scratch 不暴露；重复从同一历史状态推进不污染旧值。
- 速度型海绵层求解 u_tt+γu_t=c²∇²u，γ_max=24c0 s⁻¹，中心差分 (1+γh/2)u_next=2u−(1−γh/2)u_prev+c²h²∇²u；核心库原有调用仍保留旧行为。源位移在实际网格时刻强制施加。吸收层并非精确无反射 PML。
- 双缝以真实开口格数及中心间距构造，宽度≥间距或超出有效域为无有效几何请求，不静默改间距；单缝同样准确。障碍物输入为半宽格数，实际宽 2w+1 格。
- 接收屏平均在保守名义飞行时间+两个源周期之后开始，记录真实采样数和时长；未开始不发布屏中心均方位移。此为测量窗策略，不保证已达严格稳态，也非精确数值因果波前。屏量是 <u²>，不直接等于物理能流。

- 旧 5% 近轴远场断言在真实时钟及边界修复后出现 17.27% 偏差；d²/(λL)≈0.82、λ/d≈1/3，有限宽缝和有限观察窗不满足充分远场近轴条件。保留该失败证据，新增真实局部极值/峰谷/对称性及独立离散方程精确解验证，不将理论点源位置当成实测峰位。完整 45 s 稳定性测试保持，专用超时增加至30 s（实际10800内部步）。

- 在线及断网单文件历史最多480份双时间层网格快照，正常连续播放每0.05 s采样（20 Hz，覆盖当前源频率范围），暂停及单步保存精确末帧；避免通用2400份网格历史导致约576MB以上状态占用。实际回放历史有限，不改变物理积分频率。整场伪彩使用固定 ±2A（零振幅时显示零）色标，屏曲线横轴峰值明示、纵轴与网格同坐标。导出真实掩模、屏面曲线和实际网格等值线，不包含栅格。

- 累积全量视觉任务在 W01 最终候选触及15分钟看门狗，H41 将原在线/离线完整断言拆分成同 SHA 两个并行公开任务，fail-fast=false，每任务仍15分钟；不减少任何已有工况。默认本地全量命令仍执行两部分。分别产出 summary-online/summary-offline 和图包，两个任务全部成功才可闭环。
