# B2 自由拓扑电路建模器（`builder-circuit-mna`）物理建模规范

- **规范 ID**：`builder-circuit-mna`（兼容 V1.0 旧 ID：`circuit-dc-capacitor-mna`）
- **核心算法**：改进节点电压法（MNA）+ 列主元 LU 消元 + 孤岛 $G_{\min}=10^{-12}\text{ S}$ 泄放 + 电容/电感二阶梯形伴随模型 + Newton-Raphson 非线性迭代（幂律小灯泡、肖克利二极管阻尼步长限幅防指数溢出）。
- **异常处理**：电源极端短路极限下触发 `SHORT_CIRCUIT` 事件提示，杜绝 `NaN`/`Infinity`。
- **V2 能力**：`ControlHandle` 画布拖拽变阻、`SceneDSL` 序列化及 `DiagramIR` 黑白标准电路图导出。

## V3.1 H3：分压电路小灯泡（定量模型与显示契约）

20 Ω 理想滑动变阻器下段 R_d=clamp(R_p,0,20)，上段 R_u=20−R_d。电源 E、内阻 r≥0、上段串联，再到滑片节点 V_L；下段和灯泡并联接地。灯泡正向近似幂律 I_L=0.25(|U_L|+10⁻⁶)⁻⁰·³⁵U_L（不是额定灯泡的真实热动态模型）。理想电流表串在灯泡支路，理想电压表并联在灯泡两端，对求解无负载。内部求解仍使用 MNA/NR，串联 r+R_u 合并消元；实际电源外端 U_s=E−I_s r，与灯泡 U_L 区分。节点数组兼容保留 [0,E,U_L]；terminalVoltage 在此模式兼容旧接口仍表示 U_L，新增明确观测量 sourceTerminalVoltage、lampVoltage、lampCurrent、sourcePower、internalLoss、upperLoss、lowerLoss、dividerLowerResistance、dividerUpperResistance。

- KCL: I_s=I_d+I_L；KVL: E=I_s(r+R_u)+U_L；P_s=I_s²r+I_s²R_u+I_d²R_d+U_L I_L。
- 0 Ω 下端点：灯泡两端等势、I_L=0，I_s=E/(20+r)。20 Ω 上端点且 r=0：U_L=E，I_d=E/20，I_s=I_d+I_L。用解析拓扑约化处理精确零电阻，避免奇异矩阵，不再把 0/20 Ω 隐式钳成 1/19 Ω。
- 等势导线为相同颜色，电阻/负载跨越的电势差才渐变；色带按 0～E 统一青蓝/琥珀/珊瑚，E=0 全部等势。电流箭头为约定正电流方向的示意，动画相位来自仿真 t（暂停时停止），速度仅为可视化映射，不当作漂移速度。理想电压表支路无电流箭头。
- 主图、滑片拖拽和 DiagramIR 共用世界几何；曲线坐标注明 A/V，点位由同一灯泡定律与 MNA 实时工作点产生；灯泡光晕按实际 P_L 视觉压缩。此静态分压预设没有开关与电容，不能用 RC 开关假装断开灯泡。其他拓扑独立验收。

## V3.1 H8：其余五拓扑的真实物理边界（本轮物理子项）
- 纯阻闭合与串并联使用现有线性 MNA；精确 0 Ω 支路以零伏电压源约束等势，源支路电流从 MNA 电压源未知量读取，避免内阻趋零时两个近等电势相减。理想 E 与全部零阻抗回路在 E≠0 时无有限解、E=0 时无唯一电流；仅保留有限安全占位字段，并以 idealShort/solutionDefined=0 明示不可读作测量值。有限内阻的外部零欧姆短接仍有解 I=E/r。
- RC 充电和放电是单状态、分段常参线性系统：U_C(t+h)=U_C(t)+(E_th-U_C(t))[-expm1(-h/(R_th C))]，I_C=(E_th-U_C)/R_th。充电 E_th=E、R_th=r+R1，放电 E_th=0、R_th=R1；电源断开后源电流为零。切换参数时电容电压连续而电流可以跃变；不继承旧伴随电流。充电初始 U_C=0，独立放电预设初始 U_C=E。
- 电桥预设明确从开路稳态电容电压开始，不假装未充电。每一步 MNA 求开路 V3−V4 与杀源后从4至3注入1A所测 R_th；同一单状态精确指数演化，随后以电容电压约束 MNA 求实际节点及3→4被动电流。稳态电荷符号 Q=C(V3−V4)，储能非负，有限时间不会瞬时跳到新稳态。此解析降阶仅适用于这里的一阶 RC 拓扑，不替换通用梯形 MNA。
- 纯电阻、非线性灯泡/二极管无电容，不产生虚构电荷/储能；非线性零串阻与极端指数模型仍需后续专项，不能把指数限幅当作器件真实反向击穿或大电流模型。

### H8 非分压拓扑表示与数值适用边界
- 画布、SVG/TikZ 图形共用实际支路连接与元件符号；混联分流、电桥两组上下电阻和跨中点电容分别展示。RC 放电独立闭合回路不含电源；网页及单文件现有参数修改会重置初态，本轮不宣称热切换连续性。电容状态连续性只在引擎固定 C、分段恒定参数测试中成立。
- 非线性零串阻灯泡直接采用幂律模型；直接二极管在 E/V_T≤40 内采用指数模型，超出时明确不提供数值解。其他串阻下使用原非线性求解器及指数限幅近似。此限制是数值模型边界，并非真实器件安全工作范围。
- 理想短路或模型超界时不发布虚构电流/电压/功率观测量，仅发布 solutionDefined=0。实际支路与观测口径由独立测试验证；真实课堂/GPU、八维及全部拓扑热切换尚待验证。

### H8 补验：实际时钟、样本和运行时守恒
- 离线切片固定步长积分时间单独累计，不从低频示波器采样反推；暂停时保存真实最后一帧，画布、面板、曲线末点同一物理时间。实时面板仍低频刷新，不把实时不同步的帧率差当作物理状态差；暂停和单步强制同步。只有单一样本时明确显示暂无时间序列。
- RC 运行时检验回路 KVL、源支路连接及瞬时功率 E I_s = I²R_eff + U_C I_C；电桥检验源节点与两中点 KCL、跨电容端电压及含电容吸收功率的平衡；非线性负载检验 KCL、KVL、器件伏安律及回路功率。无效理想电路不假造通过的守恒报告。原独立测试容差不放宽。

## H68 B2 展示层与离线相机
- 灯泡玻璃、反射高光、暖光晕与放射短线为装饰性发光示意，按实际 P_L 单调映射，零功率无暖光晕，不表示真实温度、光通量或辐射方向。电路标准圆形边界及两端连接、原灯丝/电路符号、DiagramIR、MNA 和伏安曲线采样不改动。
- 数字表头保留原值及单位；表壳/玻璃面和滑片环只改变显示，滑片环中心仍为同一真实世界坐标。等势配色、电流箭头、理想电压表支路无电流、短路无解规则不变。
- 独立切片右侧参数栏已独立布局，六拓扑使用实际画布宽度而非再次预留300px。在线默认相机保持不变。器材工具栏改为明确的电路符号图标，仍只切换原有预设拓扑，不假装新增任意器件布线功能。
- 独立实机从 E=(r+R_u)(U_L/R_d+I_L)+U_L 另行二分求根，检查两滑片端点、E=0、r=0上端点、画布表头/单位/标签、居中及投影对比度。

- H68 静态分压灯泡独立切片默认收起时序示波器，保留可展开入口。收展不复位、不停止或伪造采样，复用现有真实物理时钟和历史；离开分压拓扑再进入时默认收起，RC 等动态拓扑仍自动显示对应通道和真实末样本。
