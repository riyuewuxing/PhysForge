# T01 汽缸活塞、水银柱与变质量充放气模型（thermo-piston-gas-laws）物理与数值规格书

## 1. 物理背景与课标对照
- 对应人教版《选择性必修三》第二章《气体、固体和液体》（玻意耳定律、查理定律、盖-吕萨克定律、理想气体状态方程及变质量充放气模型）。
- 核心方程：
  - 理想气体常量：$R = 8.31446261815324\text{ J/(mol}\cdot\text{K)}$；严格保持 $PV/(nRT) = 1$；
  1. **带卡口竖直汽缸 (`stop-pin-cylinder`)**：
     - 活塞质量 $m_p$、面积 $A$、大气压 $P_0$，等压平衡压强 $P_{\text{eq}} = P_0 + m_p g / A$；
     - 采用方向约束的 `bisectEvent` 管理离散模态切换：`pinned`（卡口限位容积 $V_{\text{pin}}$ 下等容升温）$\to$ `bisectEvent` 精确捕获脱离卡口临界温度 $T_{\text{crit}} = \frac{P_{\text{eq}} V_{\text{pin}}}{n R}$ $\to$ `floating`（等压自由膨胀 $V = \frac{n R T}{P_{\text{eq}}}$）。
  2. **倾转水银柱玻璃管 (`mercury-tube-tilt`)**：
     - 密闭气体压强 $P = P_0 + \rho_{\text{Hg}} g h_{\text{Hg}} \sin\theta$，水银柱高度换算 `76 cmHg = P0`，检验管长边界溢出判别。
  3. **变质量打气与抽气 (`multi-stroke-pump`)**：
     - 每次抽气等温膨胀后分断，经 $k$ 次抽气容器压强解析通式：$P_k = P_0 \left(\frac{V}{V + \Delta V}\right)^k$。

## 2. 单元测试与精度卡点
1. 全流程任意时刻理想气体状态比误差 $|PV/(nRT) - 1| < 10^{-10}$；
2. 多次抽气数值迭代与 $P_0 (V/(V+\Delta V))^k$ 相对误差 `< 10^{-10}`；
3. 卡口汽缸脱离临界温度捕获误差 `< 10^{-7}\text{ K}`；
4. 边界条件（`dt=0`, $\theta=0$, $k=0$）无 `NaN` / `Infinity`。

## H44 物理求解修订（候选实现；以同 SHA 实际测试与验收为准）
- 竖直活塞无摩擦、准静态、下限位。统一取 g=9.8 m/s²，P0=101325 Pa，固定 n。独立初温 T0（默认 260 K）与目标温度 T*；按给定温变速率达到目标并保持。V=max(Vpin,nRT/Peq)，P=nRT/V，Peq=P0+mg/A；临界温度 Tc=Peq Vpin/(nR)。加热离开与降温触及的事件时间使用共享 bisectEvent 对真实温度推进求根（时差 ≤1e-7 s；线性温变解析解为独立参照），事件点精确落在 (Vpin,Peq)，跨越大步仍记录 P-V 拐点；初态已浮起不伪造脱离事件。气体对外做功 W=∫Pext dV=Peq(V−Vinitial)，膨胀为正、压缩为负、卡口上等容为零。未指定热容，不推断 Q 或 ΔU。
- 水银管以封闭端到开口方向为轴，θ 是其相对水平面有向倾角；等温、同横截面、无毛细、无泄漏的理想液柱。每个角度是从同一水平参考独立比较，并非不可逆历史；水平气柱 L0=min(30 cm,L−h0−2 cm)，固定 n0=P0 A L0/(RT)。统一使用 P=P0(1+h sinθ/76)。无溢出：h=h0，l=L0/(1+h0 sinθ/76)，若 l+h0≤L。溢出：解 (L−h)(1+h sinθ/76)=L0，0≤h≤h0，l=L−h，保持固定 n0；不得先以满液柱计算 l 再重算 P。合法范围内单调有唯一根。压力、重量及管壁法向支持使用同一液柱单位换算；不模拟实际水银操作、安全或流体动力学。零倾角及溢出边界连续。
- 打气/抽气是理想等温、无死体积、有理想阀门的定容储气罐操作序列，不是封闭气体的准静态 P-V 过程。抽气每次 Pj=P(j−1)V/(V+ΔV)，打气每次吸入大气压下 ΔV 的气体，Pj=P(j−1)+P0ΔV/V。记录 j=0…k 的压力、固定容积与气体物质的量（各级 n=Pj V/RT），最终状态取第 k 级；不以时间动画或重复 P-V 点伪造冲程，不宣称气筒做功为零。应展示级次—压强图。
- 静态倾管、泵模式 t=0；模式专属参数、力矢量、装置图、读数与矢量导出取同一求解结果。保留原 3 项独立测试，新增上述 9 项可编译的真实失败测试。须在公开仓库实际红灯、修复后同 SHA 回归并在线/离线视觉验收。
